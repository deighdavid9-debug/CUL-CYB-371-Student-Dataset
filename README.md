# CUL-CYB 371 - Data Mining and Data Warehousing
## Assignment Two: Fictional Student Dataset

This project contains a fictional dataset of 15 students.

### Dataset fields
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score

### Files
- `create_dataset.py` - Python program that creates the dataset.
- `student_dataset.csv` - Dataset saved in CSV format.

### How to run
1. Install Python 3 if it is not already installed.
2. Open a terminal in this folder.
3. Run: `python create_dataset.py`
4. The program creates `student_dataset.csv`.

All student records are fictional and created for academic purposes.
